# Data Wrangling and Functions in R

This is my **second R project**, following my basic beginner project. In this project, I worked with **real-world datasets**, created **custom functions**, performed **data wrangling**, and visualized results.  

## Key Highlights

### Astronaut Data Analysis
I analyzed astronaut data to explore trends such as total mission hours, the share of female and civilian astronauts, and nationality distributions.  
- **Data source:** The astronaut dataset can be found [here](https://data.mendeley.com/datasets/86tsnnbv2w/1).  

### Password Strength Checker
I implemented a function that evaluates passwords based on strength and provides a descriptive rating.  

### Monty Hall Simulation
I simulated the classic Monty Hall problem and extended it to any number of doors. This allows comparison of the probability of winning when switching versus staying, and results are visualized using plots.  

## Skills and Tools

- **R Programming:** Data manipulation, summarization, and visualization.  
- **`dplyr` & `tidyverse`:** Filtering, grouping, and summarizing data.  
- **`ggplot2`:** Creating clear and informative plots.  
- **Custom Functions:** Writing reusable R functions for simulations and analysis.  

This project helped strengthen my **R programming and data analysis skills**, with a focus on reproducible workflows.
